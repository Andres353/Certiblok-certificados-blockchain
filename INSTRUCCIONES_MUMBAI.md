# 🚀 Guía Rápida: Agregar Polygon Mumbai a MetaMask

## ⚡ Método Rápido (30 segundos)

1. **Abre**: https://chainlist.org/
2. **Busca**: "Mumbai" o "80001"
3. **Conecta MetaMask** (botón arriba a la derecha)
4. **Clic en "Add to MetaMask"** en la red que diga:
   - Network: **Mumbai**
   - Chain ID: **80001**
5. **¡Listo!** Cambia a la red Mumbai en MetaMask

## 📝 Método Manual (si prefieres)

1. Abre MetaMask
2. Clic en la red actual (arriba, donde dice "Polygon Mainnet")
3. **"Add Network"** o **"Agregar Red"**
4. Completa estos datos exactos:

```
Network Name: Polygon Mumbai Testnet
New RPC URL: https://rpc-mumbai.maticvigil.com
Chain ID: 80001
Currency Symbol: MATIC
Block Explorer URL: https://mumbai.polygonscan.com
```

5. **Guardar**
6. Cambiar a "Polygon Mumbai Testnet"
